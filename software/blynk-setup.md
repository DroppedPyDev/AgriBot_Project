# Blynk Setup

The prototype uses the Blynk Android application for remote control and sensor display.

## Virtual pins

- `V1`: Soil-moisture value
- `V2`: Temperature
- `V3`: Humidity
- `V4`: Servo-angle input

## Security

Do not commit the Blynk authentication token or Wi-Fi credentials. Keep them in a private local copy of the sketch, and rotate any credentials that were previously exposed in printed reports or photographs.
