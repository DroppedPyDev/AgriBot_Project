# Software Libraries

- `ESP8266WiFi.h` — Wi-Fi support for ESP8266
- `BlynkSimpleEsp8266.h` — Blynk connectivity
- `DHT.h` — DHT temperature/humidity sensor support
- `Servo.h` — Servo control on ESP8266

Install compatible versions through the Arduino IDE Library Manager where available.
