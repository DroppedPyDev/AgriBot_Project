# Testing Checklist

- [ ] Confirm the exact ESP8266 board model.
- [ ] Verify every GPIO connection against the physical prototype.
- [ ] Verify motor-driver supply and common ground.
- [ ] Test each motor direction with the wheels lifted from the ground.
- [ ] Test servo endpoints without mechanical obstruction.
- [ ] Verify relay logic before connecting the pump or cutter.
- [ ] Calibrate the soil-moisture sensor.
- [ ] Confirm the DHT sensor model and readings.
- [ ] Test Blynk access using non-public credentials.
- [ ] Check emergency stop behavior and power isolation.
